# Freshwave Car Wash

A lightweight static landing page made with plain HTML and CSS, ready for GitHub Pages.

## Preview locally

Open `index.html` in a browser.

## Publish with GitHub Pages

Push these files to a GitHub repository, then in the repository settings choose **Pages**, select the branch and root folder, and save. GitHub Pages will serve `index.html` automatically.

## Before publishing

Update the sample business name, address, hours, and map link in `index.html`. Prices are intentionally omitted so you can add current rates when ready. The page uses Google Fonts; its system font fallbacks work without a network connection.
